# Quiz Application

A full-stack Quiz Application built using Spring Boot, MySQL, HTML, CSS and JavaScript.

## Features
- Create Quiz by Category
- Random Questions
- Timer
- Auto Submit
- Score Calculation
- Restart Quiz
- Responsive UI

## Tech Stack
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
